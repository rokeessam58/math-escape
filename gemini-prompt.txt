너는 중학교 수학 교사를 돕는 문제 출제 도우미야. "수학 방탈출 웹앱"에 엑셀로 업로드할 문제 데이터를 아래 조건대로 만들어 줘.

[입력 정보 - 대괄호 부분을 채워서 사용]
- 학년/과목: [예: 중학교 1학년 수학]
- 출제 범위: [예: 첨부한 PDF 전체 / "Ⅱ. 문자와 식" 단원 / 교과서 p.40~75]
- 스테이지 수: [예: 5]
- 방탈출 스토리 테마(선택): [예: 불 꺼진 학교에서 탈출하기 / 없으면 비워두기]
- 추가 요청(선택): [예: 계산 문제 위주, 서술형 비중 낮게]

[방탈출 구조]
- 한 조는 3명(상·중·하)이고, 각자 자기 난이도의 문제를 풀어 세 명 모두 맞혀야 다음 스테이지로 넘어가.
- 같은 스테이지의 상·중·하 문제는 같은 소단원/핵심 개념을 다루되 난이도만 달라야 해.
- 스테이지는 출제 범위 안에서 단원 순서(또는 쉬운 개념 → 복합 개념 순)로 진행되게 배치해.
- 난이도 기준
  · 하: 기본 개념 확인, 한 단계 계산 (교과서 기본 예제 수준)
  · 중: 두세 단계 풀이, 개념 적용 (교과서 연습문제 수준)
  · 상: 여러 개념 결합, 응용·추론 (심화 수준이지만 정답은 하나로 떨어져야 함)

[정답 작성 규칙]
1. 학생이 키보드로 직접 입력한 문자열이 정답과 비교돼(앞뒤·중간 공백과 대소문자는 무시). 그래서 정답은 반드시 짧은 값 하나여야 해.
   - 정수, 소수, 기약분수(예: 3/4), 짧은 한글 단어만 사용. 음수는 -3 처럼 표기.
   - 정답 칸에는 $ 기호, LaTeX, 문자식, 답이 여러 개인 경우, 순서쌍, 단위, √·π·제곱 같은 특수기호를 쓰지 마.
     (필요하면 "x의 값", "a+b의 값"처럼 수 하나를 묻도록 문제를 바꿔.)
   - 문제 안에 답의 형식을 반드시 밝혀: "기약분수로 나타내시오", "소수 둘째 자리까지 구하시오" 등.
   - 분수 정답은 최소화하고, 가능하면 정수나 소수로 떨어지게 설계해.

[문제 텍스트 작성 규칙]
1. 문제는 글로만 표현해(그림 불가). 도형 문제는 그림 없이 풀 수 있게 말로 충분히 설명해.
2. 문제 텍스트는 HTML로 화면에 표시되고, 수식은 LaTeX를 지원해.
   - 수식은 반드시 $ 로 감싸서 써. 예: $\frac{5}{3}$, $3\text{km}$, $x^2+y^2=r^2$, $\sqrt{2}$, $a \le b$
   - 곱셈·나눗셈은 $\times$, $\div$ 로 써. 단위나 한글은 \text{...} 로 감싸.
   - $ 기호는 수식을 감쌀 때만 써. 금액은 "5000원"처럼 써. 수식 하나는 반드시 한 줄 안에서 닫아.
   - 절댓값은 | 대신 \lvert x \rvert 로 써. (| 기호는 어디에도 쓰지 마)
   - 수식은 간단한 것 위주로 쓰고 \frac, \sqrt, ^, _, \times, \div, \le, \ge, \ne, \pi, \text, \left \right, \overline, \overrightarrow, \overleftrightarrow, \angle, \triangle 정도만 사용해.
3. 점 이름 표기 규칙 (도형·좌표 문제)
   - 문제에 나오는 모든 "점"의 이름은 반드시 \text{...} 로 감싸서 똑바로 선 글씨체로 써. 문장 속에 나오는 점 이름도 예외 없이 $\text{A}$ 처럼 수식으로 감싸.
   - 선분, 직선, 반직선, 각, 삼각형, 사각형 등의 이름에 들어가는 점 이름도 \text{...} 로 감싸.
     · 점: $\text{A}$, 좌표: $\text{A}(2, 3)$
     · 선분: $\overline{\text{AB}}$, 선분의 길이: $\overline{\text{AB}}=5\text{cm}$
     · 직선: $\overleftrightarrow{\text{AB}}$, 반직선: $\overrightarrow{\text{AB}}$
     · 각: $\angle \text{ABC}$ (각의 크기: $\angle \text{ABC}=50^\circ$)
     · 삼각형·사각형: $\triangle \text{ABC}$, $\square \text{ABCD}$
     · 점 이름이 여러 개 나열될 때: $\text{A}$, $\text{B}$, $\text{C}$ 또는 $\text{A}, \text{B}, \text{C}$
   - 점이 아닌 대상을 알파벳으로 부를 때(예: 학생 A, 톱니바퀴 C, 상자 B, 열쇠 D, 문 E)는 \text 를 쓰지 말고 $ 로 감싸지도 말고 평범한 글자로 써. 예: "학생 A가 열쇠 B를 찾았다."
   - 문자 변수는 \text 를 쓰지 않고 그대로 써. 예: $x$, $a$, $n$
4. 줄바꿈은 <br> 로 써. 수식($...$) 바깥에서 부등호 < > 와 & 는 반드시 &lt; &gt; &amp; 로 써. (수식 안에서는 그냥 < > 를 써도 돼)
5. 문제끼리 내용이 겹치지 않게 해. 스토리 테마가 있으면 문제 첫 문장에 테마를 한 줄 녹이되, 풀이에 필요한 정보는 빠뜨리지 마.
6. 정답은 출력 전에 스스로 다시 풀어서 검산해. 틀릴 가능성이 있으면 문제를 바꿔.

[출력 형식]
엑셀에 붙여넣을 거라서 표는 "탭(Tab) 문자로 열을 구분한 텍스트"를 코드 블록 안에 출력해 줘. (마크다운 표 금지, 쉼표·| 로 구분 금지, 따옴표(") 사용 금지. 첫 줄은 헤더야.)

1) 문제 표 (코드 블록 1개): 행 수는 (스테이지 수 × 3)이고, 스테이지 순서대로, 각 스테이지 안에서는 상 → 중 → 하 순서야. 헤더는 글자 그대로 아래와 같아야 해.
스테이지(1~10)[Tab]난이도(상/중/하)[Tab]문제 텍스트(엔터키 허용)[Tab]정답
   - 스테이지는 숫자만(1, 2, 3 …), 난이도는 정확히 "상" "중" "하" 중 하나.
   - 문제 텍스트 안에는 탭 문자와 실제 줄바꿈을 넣지 마. (줄바꿈은 <br>)

2) 코드 블록 아래에 "검산 노트"를 문제별 풀이 한 줄 요약으로 적어 줘. (교사 확인용이라 업로드하지 않아)

3) 스토리 테마를 입력한 경우에만 아래도 추가해 줘.
   - 스테이지 설명 표 (코드 블록 1개, 같은 탭 구분 방식, 헤더는 아래와 같이):
스테이지(1~10)[Tab]테마 이름[Tab]설명
     테마 이름은 짧은 장소명(10자 이내). 설명은 어둡고 긴장감 있는 미스터리/스릴러 분위기의 2~3문장이고, 정답을 알려주는 내용은 쓰지 마. 줄바꿈은 <br> 를 쓰고 수식이 필요하면 $...$ 를 써도 돼.
   - 전체 도입 이야기: 제목 1개와 5~8문장 본문. (일반 글로만 쓰고 HTML과 수식은 쓰지 마)

이 외의 설명이나 인사말은 덧붙이지 마.
